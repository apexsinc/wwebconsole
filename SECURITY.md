# Security Policy

## Supported versions

Security fixes are applied to the `main` branch of WWebConsole.

## Reporting a vulnerability

Email **security@wwebconsole.com** (or your ops contact) with:

- Description of the issue and impact
- Steps to reproduce (PoC if available)
- Affected URL / endpoint / component

Please do **not** open a public GitHub issue for active vulnerabilities.

We aim to acknowledge reports within 3 business days.

## Scope

In scope:

- `wwebconsole.com`, `www.wwebconsole.com`, `admin.wwebconsole.com`
- Auth, account, station, share/TV, and admin APIs
- Session handling and credential storage

Out of scope:

- Third-party WeatherLink / Davis APIs
- Cloudflare platform issues (report to Cloudflare)
- Social engineering of staff mailboxes

## Safe harbor

Good-faith research that avoids data destruction, privacy violations, and service disruption is welcome. Do not attempt to access other customers’ data.
